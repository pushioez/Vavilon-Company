# VAVILON — сайт студии

Монохромный sci-fi скролл-сторитейл для студии **Vavilon** (разработка сайтов, ПО для автоматизации бизнеса и мобильных приложений).

Статический сайт: чистый HTML + CSS + ванильный JavaScript, без сборки и без зависимостей. Пять отрендеренных артефактов (a–e) левитируют над постоянным туманом и анимируются через CSS 3D-трансформы, управляемые скроллом.

## Структура

```
vavilon-site/
├── index.html        # разметка и контент
├── css/
│   └── styles.css    # все стили, туман, HUD, адаптив
├── js/
│   └── main.js       # скролл-логика, переходы, звук (Web Audio)
└── assets/
    ├── a.jpg         # блок 1 / 6 — арктика, иглу
    ├── b.jpg         # блок 2 — кристалл
    ├── c.jpg         # блок 3 — камень
    ├── d.jpg         # блок 4 — ледяной куб
    └── e.jpg         # блок 5 — металлическое кольцо
```

## Локальный запуск

Любой статический сервер. Например:

```bash
python3 -m http.server 8778
```

Затем открыть http://localhost:8778

## Публикация на GitHub Pages

1. Залить папку в репозиторий (файл `index.html` должен лежать в корне).
2. Settings → Pages → Source: `Deploy from a branch`, ветка `main`, папка `/ (root)`.
3. Сайт будет доступен по адресу `https://<username>.github.io/<repo>/`.
